- [x] `docker compose up` поднимает PostgreSQL 17 + pgvector.
- [x] Скелет Python-пакета: config из `.env`, подключение к БД.

## Вечер 4 — бизнесовый корпус и редизайн

Демо на документации FastAPI выглядело слишком «снизошёл-до-примера».
Переориентировал кейс на живой сценарий: ассистент первой линии поддержки
торговой компании.

- [x] Корпус: вместо доков FastAPI — база знаний поддержки из 29 документов
      (доставка, оплата, возвраты, гарантия, брак, опт, FAQ, регламент линии),
      лежит в `data/kb` прямо в репо.
- [x] Эмбеддинги переведены с API на локальный bge-m3 на GPU
      (sentence-transformers), внешние вызовы для векторов больше не нужны.
- [x] Веб-интерфейс переписан: светлая тема, слева история вопросов,
      справа ответ с источниками; источники ведут на сами документы (`/kb/...`).
- [x] Промпт и тексты интерфейса переписаны под роль «ассистент поддержки».
- [x] Eval-набор и фикстуры интеграционных тестов переведены на новый корпус,
      замеры перегнаны, README обновлён.

**Выход вечера**: кейс выглядит как рабочий инструмент, а не как туториал.
