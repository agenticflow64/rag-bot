# Сценарий демо-видео

Длительность: до 2 минут. Одна съёмка экрана, без монтажа.
Перед записью поднять проект: `docker compose up -d`, `python -m app.ingest`,
`python -m app.web` → http://localhost:8800.

## Чек-лист перед записью

- [ ] `docker compose down -v` → `up -d` → ингест поднимается чисто с нуля.
- [ ] Ингест прогнан, в базе свежие чанки (`SELECT count(*) FROM chunks;`).
- [ ] Оба demo-вопроса и «вне-базовый» отработаны заранее (репетиция).
- [ ] Таблица замеров в README заполнена, помечена «демо».
- [ ] Терминал: увеличенный шрифт, светлая тема, нет лишних вкладок.
- [ ] Браузер: окно ~1280px, история вопросов слева не пустая (задать пару вопросов заранее).
