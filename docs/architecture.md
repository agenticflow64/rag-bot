# Архитектура

RAG-конвейер: от документа базы знаний до ответа с цитатами.

```mermaid
flowchart LR
    A[База знаний<br/>29 markdown-документов<br/>data/kb] --> B[Чанкинг<br/>по заголовкам, 500–800 токенов<br/>перекрытие 100]
    B --> C[Эмбеддинги<br/>bge-m3 локально на GPU<br/>кэш в БД по хэшу чанка]
    C --> D[(PostgreSQL 17 + pgvector<br/>HNSW-индекс)]

    Q[Вопрос сотрудника поддержки] --> E[Retrieval<br/>эмбеддинг вопроса<br/>top-k = 5]
    D --> E
    E -->|топ-скор ниже порога| R[Отказ:<br/>«Вне базы знаний»<br/>без вызова LLM]
    E --> F[Генерация<br/>стриминг, только по чанкам]
    F --> G[Ответ с цитатами [n]<br/>источники — ссылки на /kb/...]
    D --> G

    W[Веб UI / CLI] --> Q
```

## Компоненты

| Модуль | Назначение |
|---|---|
| `app/chunking.py` | разбор по заголовкам #..####, окна с перекрытием, путь раздела в метаданных |
| `app/ingest.py` | чанки → эмбеддинги (с кэшем по sha256 контента) → pgvector; идемпотентный |
| `app/embeddings.py` | локальный эмбеддер bge-m3 (sentence-transformers, GPU), ленивая загрузка модели |
| `app/llm.py` | генерация: GLM/OpenRouter (OpenAI-совместимые), авто-fallback, стриминг; эмбеддинги: local или API |
| `app/retrieval.py` | top-k по косинусной близости, порог релевантности |
| `app/prompts.py` | сборка промпта с пронумерованными фрагментами, разбор цитат [n] |
| `app/pipeline.py` | полный конвейер вопрос → ответ + источники + метрики latency |
| `app/web.py` + `app/static/` | FastAPI, SSE-стриминг, страница интерфейса, выдача документов `/kb/{файл}` |
| `app/ask.py` | CLI-режим для тестов и скриптов |

## Схема данных (PostgreSQL)

- `chunks` — чанк: файл, раздел, url (`/kb/файл`), текст, эмбеддинг `vector(1024)`, HNSW-индекс;
- `embed_cache` — кэш эмбеддингов `sha256(контент) → вектор` (повторный ингест
  не пересчитывает векторы);
- `meta` — текущая модель эмбеддингов (при смене векторы пересчитываются).

## Двухуровневая защита от галлюцинаций

1. **Retrieval-порог**: если косинусная близость топ-чанка ниже порога —
   «Вне базы знаний» возвращается без вызова LLM (быстро и бесплатно).
2. **Промпт**: генерация идёт строго по пронумерованным фрагментам со ссылками [n];
   модель инструктирована не выдумывать за пределами контекста.

## Границы решения

- Корпус: внутренняя база знаний поддержки в `data/kb` (29 документов);
  документы лежат в репо, ингест читает их напрямую.
- Эмбеддинги локальные: bge-m3 на GPU хоста; без GPU работает на CPU (медленнее).
- Ответ всегда сопровождается источниками; без релевантного чанка — отказ.
- Latency генерации зависит от тарифа LLM-провайдера (замеры — на бесплатном).
