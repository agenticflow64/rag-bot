# Архитектура

RAG-конвейер: от сырой документации до ответа с цитатами.

```mermaid
flowchart LR
    A[Документация FastAPI<br/>41 markdown-файл] --> B[Чанкинг<br/>по заголовкам, 500–800 токенов<br/>перекрытие 100]
    B --> C[Эмбеддинги<br/>GLM API / OpenRouter<br/>кэш в БД по хэшу чанка]
    C --> D[(PostgreSQL 17 + pgvector<br/>HNSW-индекс)]

    Q[Вопрос пользователя] --> E[Retrieval<br/>эмбеддинг вопроса<br/>top-k = 5]
    D --> E
    E -->|топ-скор ниже порога| R[Отказ:<br/>«Вне базы знаний»<br/>без вызова LLM]
    E --> F[Генерация<br/>стриминг, только по чанкам]
    F --> G[Ответ с цитатами [n]<br/>список источников со ссылками]

    W[Веб UI / CLI] --> Q
```

## Компоненты

| Модуль | Назначение |
|---|---|
| `app/download_docs.py` | скачивает markdown по списку `data/links.txt` в `data/docs/` |
| `app/chunking.py` | разбор по заголовкам #..####, окна с перекрытием, путь раздела в метаданных |
| `app/ingest.py` | чанки → эмбеддинги (с кэшем по sha256 контента) → pgvector; идемпотентный |
| `app/llm.py` | провайдеры GLM/OpenRouter (OpenAI-совместимые), авто-fallback, стриминг |
| `app/retrieval.py` | top-k по косинусной близости, порог релевантности |
| `app/prompts.py` | сборка промпта с пронумерованными фрагментами, разбор цитат [n] |
| `app/pipeline.py` | полный конвейер вопрос → ответ + источники + метрики latency |
| `app/web.py` + `app/static/` | FastAPI, SSE-стриминг, тёмная тема |
| `app/ask.py` | CLI-режим для тестов и скриптов |

## Схема данных (PostgreSQL)

- `chunks` — чанк: файл, раздел, url, текст, эмбеддинг `vector(1536)`, HNSW-индекс;
- `embed_cache` — кэш эмбеддингов `sha256(контент) → вектор` (экономия токенов
  при повторных ингестах);
- `meta` — текущая модель эмбеддингов (при смене векторы пересчитываются).

## Двухуровневая защита от галлюцинаций

1. **Retrieval-порог**: если косинусная близость топ-чанка < 0.30 —
   «Вне базы знаний» возвращается без вызова LLM (быстро и бесплатно).
2. **Промпт**: генерация идёт строго по пронумерованным фрагментам со ссылками [n];
   модель инструктирована не выдумывать за пределами контекста.

## Границы решения

- Источники: открытая документация FastAPI (MIT), список в `data/links.txt`.
- Ответ всегда сопровождается источниками; без релевантного чанка — отказ.
- Latency генерации зависит от тарифа LLM-провайдера (замеры — на бесплатном).
