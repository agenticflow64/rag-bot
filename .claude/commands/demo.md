# Чек-лист записи демо-видео

Пройди чек-лист записи демо по сценарию `docs/demo-script.md`.

## Перед записью

- [ ] Прочитай `docs/demo-script.md` целиком.
- [ ] `docker compose down -v` → `docker compose up` — проект поднимается с нуля без ошибок.
- [ ] Ингест прогнан заново, в базе свежие чанки.
- [ ] Репетиция: все три вопроса из сценария (2 из базы + 1 вне-базовый) дают ожидаемые ответы.
- [ ] Таблица замеров (hit rate / latency) заполнена, помечена «демо».
- [ ] Экран: шрифт терминала увеличен, лишние вкладки/окна закрыты, уведомления выключены.
- [ ] Открыты заготовки: README, терминал, схема архитектуры, вкладки docs для ссылок из ответов.

## Во время записи

- [ ] Хронометраж по таймкодам сценария, суммарно не больше 2 минут.
- [ ] Клик по ссылке-источнику в ответе бота обязателен (таймкод 0:35–0:55).
- [ ] Показать отказ «нет ответа в базе» на вне-базовом вопросе.
- [ ] Говорить спокойно, без жаргона — видео смотрят не только бэкендеры.

## После записи

- [ ] Просмотреть запись: звук слышен, текст читаем, ссылки кликаются на записи.
- [ ] Если дубль нужен — перезаписать целиком, не склеивать.
- [ ] Положить файл как `docs/demo.mp4` (в .gitignore при необходимости) или ссылку на видео — в README.
