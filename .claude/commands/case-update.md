# Обновить кейс в портфолио

Обнови раздел «Результат» в README проекта замерами и продублируй кейс в портфолио.

## Шаги

1. Прочитай свежие замеры (таблица из последнего прогона скилла `rag-eval`:
   hit rate источника, latency, доля отказов).
2. Обнови раздел «Результат» в `README.md` (корень проекта):
   - таблица метрик;
   - пометка «демо, цифры из локальных замеров»;
   - формат кейса не ломать: Задача → Решение → Результат.
3. Продублируй обновлённый кейс в `/home/mattew/freelans-way/portfolio/case-rag-bot/README.md`
   (директорию создать, если её нет; копия — публичная версия кейса).
4. Проверь перед записью в portfolio-копию:
   - нет секретов (ключей, паролей);
   - нет ничего из основного места работы (внутренних названий работодателя);
   - все цифры помечены «демо».
5. Сделай коммит с сообщением вида
   `docs: обновить результат замерами (демо)`.

## Аргументы

Если переданы аргументы ($ARGUMENTS) — использовать их как уточнение
(например, какие метрики добавить или что поменять в тексте кейса).
